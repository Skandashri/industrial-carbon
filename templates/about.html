About This Project

Project Title

AI-Driven Industrial Carbon Emission Forecasting using Machine Learning and IoT.

Objective

This project predicts industrial CO₂ emissions based on energy consumption, temperature, humidity, production output and operating conditions.

Technologies Used

  • Python
  • Flask
  • Machine Learning
  • Random Forest Regressor
  • MySQL
  • Pandas
  • NumPy
  • Scikit-learn
  • HTML
  • CSS

Machine Learning Model

Random Forest Regressor was trained using the hybrid industrial dataset to forecast CO₂ emissions with high accuracy.

Future Scope

  • Real-time IoT integration
  • ESP32-based monitoring
  • Cloud dashboard
  • Live carbon emission tracking
  • Automatic alerts
