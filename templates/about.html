About the System

Real-time IoT Telemetry & AI-Driven Industrial Carbon Emission Forecasting using ESP32, Scikit-Learn Machine Learning, and Scope 2 Grid Emission Standards.

Project Overview & Objective

Manufacturing and heavy processing facilities contribute significantly to global carbon footprints through intensive electrical consumption. This project delivers an automated, edge-connected decision support system that calculates real-time carbon emissions and forecasts future emission loads based exclusively on core operational parameters.

By focusing strictly on Energy Consumption, Production Count, and Machine Operating Hours, the system avoids extraneous ambient noise and delivers accurate, actionable insights for factory managers and energy auditors.

Machine Learning Methodology

The analytical engine leverages an ensemble Random Forest Regressor trained on historical industrial records:

  • • Core Features: Energy Consumption (kWh), Production Output (Units), Shift Working Hour (0–23), and Weekend Schedule.
  • • Feature Normalization: Input vectors scaled via Scikit-Learn's StandardScaler.
  • • Operating Range: Trained domain: 6.48 to 19.79 kWh. Outside this range, the system applies the CEA baseline constant of 0.82 kg CO₂/kWh.

IoT Hardware Architecture

Physical data acquisition architecture designed for factory floor integration:

  • • Energy Meter: PZEM-004T AC multifunction energy module with split-core current transformer via TTL UART.
  • • Production Counter: E18-D80NK infrared optical proximity sensor triggering GPIO interrupt pulses.
  • • Operating Hours: Derived dynamically from PZEM-004T active electrical readings (no extra sensor required).
  • • Edge Controller: ESP32 Wi-Fi microcontroller transmitting JSON telemetry to Flask REST API.

Industry 4.0 Deployment Roadmap

Key scalability milestones for multi-facility enterprise deployments:

  • 01

    Multi-Machine ESP32 Sensor Grid

    Deploying dedicated ESP32 edge nodes across every production line with synchronized factory telemetry.

  • 02

    MQTT Broker Telemetry Streaming

    Scaling ingestion with Eclipse Mosquitto MQTT for lightweight, low-latency industrial publish-subscribe streams.

  • 03

    Automated Severity Threshold Alerts

    Instant webhook and SMS notifications dispatched to plant supervisors whenever forecasted emissions cross the High severity tier.

  • 04

    Deep Learning Temporal Forecasting

    Incorporation of Long Short-Term Memory (LSTM) networks for multi-day ahead carbon budgeting and peak shaving.

  • 05

    Carbon Credit & Regulatory ESG Auditing

    Automated ISO 14064 compliance tracking with carbon credit offset ledger for corporate sustainability reporting.
