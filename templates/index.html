End-to-End IoT & ML Architecture

Physical sensor data pipeline from industrial machine to AI inference and cloud dashboard.

1

Physical IoT Sensors

PZEM-004T energy meter and IR optical sensor capture machine energy, production counts, and derived active operating hours.

2

ESP32 Microcontroller

Aggregates sensor pulses and UART frames, packages data into standardized JSON payloads, and transmits over Wi-Fi via secure HTTP REST API.

3

Flask Backend & Calculation

Ingests live payload, calculates real-time Scope 2 CO₂ emissions (0.82 kg/kWh), and executes Random Forest inference for future emissions.

4

Real-Time Dashboard & MySQL

Persists audit telemetry in MySQL, displays live connection status and trend charts, and alerts operators to inefficient operating cycles.
